# Space Warrior

Небольшой 2D-шутер на Godot 4 (Forward+): корабль игрока движется по горизонтали у нижнего края
экрана и отстреливает врагов-разведчиков, которые патрулируют верхнюю полосу и время от времени
заходят на линию огня.

## Запуск

1. Установить [Godot 4.7+](https://godotengine.org/download).
2. Открыть папку проекта в Godot (`project.godot`) и дождаться импорта ассетов.
3. Нажать **Play** (F5). Главная сцена — `game/game.tscn`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение влево / вправо | `A` / `D`, стрелки |
| Огонь | `Space` |

## Структура проекта

```
assets/     спрайты: корабль игрока, враги (Kla'ed), снаряды, фон
elements/   игровые элементы-сцены со скриптами
  spaceship.gd/.tscn  корабль игрока: движение, стрельба
  bullet.gd/.tscn     пуля: полёт, урон, вспышка попадания
  impact.gd/.tscn     вспышка в точке попадания
  wall.tscn           невидимые стены по краям экрана
  enemy/scout.*       враг-разведчик: патруль, прицеливание, взрыв
game/       game.tscn — главная сцена
```

Параметры баланса (скорость, ускорение, темп стрельбы, здоровье врага, границы полосы полёта)
вынесены в `@export`-переменные и настраиваются в инспекторе.

## Ассеты

Спрайты кораблей и снарядов — из бесплатных пиксель-арт паков Foozle (серия «Void»:
Main Ship, Kla'ed). Перед публикацией проекта стоит свериться с актуальными условиями
лицензии автора и указать его в титрах.
